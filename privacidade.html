Política de Privacidade

Assistente Pessoal IA · Última atualização: 28 de setembro de 2026

1. Quem somos

O Assistente Pessoal IA é um assistente virtual que funciona pelo WhatsApp e ajuda o usuário com tarefas do dia a dia, como lembretes, organização de agenda, acompanhamento de alimentação e conversas em geral.

2. Dados que coletamos

  • Número de telefone e nome de perfil do WhatsApp.
  • Mensagens, áudios e imagens enviados ao assistente.
  • Informações compartilhadas voluntariamente (como peso, altura, objetivos e preferências).
  • Se o usuário conectar o Google Calendar: dados de eventos da agenda.

3. Uso dos dados do Google Calendar

Se o usuário autorizar a conexão, o assistente acessa o Google Calendar para criar eventos e lembretes a pedido do usuário e consultar compromissos quando ele perguntar sobre sua agenda.

Esses dados são usados apenas para oferecer essas funções ao próprio usuário. Não são vendidos, não são usados para publicidade e não são compartilhados com terceiros. O uso das informações recebidas das APIs do Google segue a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. Como usamos os dados

Para responder às mensagens, manter o contexto da conversa, enviar lembretes e personalizar o atendimento. Não vendemos dados pessoais.

5. Compartilhamento

Para funcionar, o conteúdo das mensagens é processado por provedores de tecnologia que operam o serviço (hospedagem e banco de dados em nuvem e serviços de inteligência artificial). Eles tratam os dados apenas para prestar o serviço. Não compartilhamos dados com terceiros para fins de marketing.

6. Armazenamento e segurança

Os dados ficam em banco de dados em nuvem com controle de acesso. Adotamos medidas técnicas razoáveis de proteção, mas nenhum sistema é totalmente livre de riscos.

7. Direitos do usuário

O usuário pode solicitar acesso, correção ou exclusão dos seus dados, revogar o acesso ao Google Calendar em myaccount.google.com/permissions e pedir o encerramento do uso do serviço, escrevendo para assistentepessoal49@gmail.com.

8. Retenção

Mantemos os dados enquanto o usuário utilizar o serviço. Após pedido de exclusão, os dados são removidos em prazo razoável.

9. Alterações

Esta política pode ser atualizada. A data da última atualização estará sempre no topo.

10. Contato

Dúvidas ou solicitações: assistentepessoal49@gmail.com
